# 🏢 IFC Web Viewer

> Быстрый и лёгкий браузерный 3D-просмотрщик BIM-моделей в формате IFC на базе **Three.js** и **web-ifc (WebAssembly)**.

🌐 **Онлайн демо:** [https://ailyakhinv-droid.github.io/ifc-viewer/](https://ailyakhinv-droid.github.io/ifc-viewer/)

---

## ✨ Возможности

- 🚀 **100% Client-Side** — вся обработка и парсинг IFC происходят в браузере с помощью WebAssembly (без передачи файлов на сервер).
- 📂 **Загрузка любых IFC-моделей** — через выбор файла или прямое перетаскивание (Drag & Drop).
- 📦 **Демо-модель в один клик** — кнопка «Пример модели» для мгновенного тестирования без необходимости искать IFC-файлы.
- 🎮 **3D-навигация**:
  - Вращение: зажатая ЛКМ
  - Панорамирование: зажатая ПКМ или колесо мыши
  - Зум: колесико мыши
  - Кнопка **«Вписать»** — центрирование камеры на всей модели
  - Переключение проекции: **Перспектива / Ортогональная**
  - **Каркасный режим (Wireframe)**
- 🔍 **Инспекция элементов**:
  - Подсветка элементов при наведении курсора
  - Выделение по клику
  - Информационная панель свойств: **Express ID**, **IFC Type** (IfcWall, IfcSlab, IfcDoor, IfcWindow...), **Name**, **Description**, **GlobalId** и атрибуты элемента.

---

## 🛠️ Стек технологий

- **Vite 8** — сборщик и среда разработки
- **TypeScript** — строгая типизация
- **Three.js** — 3D WebGL рендеринг и OrbitControls
- **web-ifc** — WebAssembly-парсер IFC геометрии и метаданных

## 🚀 Локальный запуск

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/ailyakhinv-droid/ifc-viewer.git
   cd ifc-viewer
   ```

2. Установите зависимости:
   ```bash
   npm install
   ```

3. Запустите локальный сервер разработки:
   ```bash
   npm run dev
   ```

4. Откройте в браузере: `http://localhost:5173/`

### Сборка для production:

```bash
npm run build
```

Собранные статические файлы будут находиться в папке `dist/`. Их можно разместить на любом статическом веб-сервере (GitHub Pages, Vercel, Netlify, Nginx и т.д.).
